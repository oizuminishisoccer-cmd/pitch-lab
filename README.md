# PITCH LAB ⚽

**育成シミュレート / 戦績管理 / スキル在庫** を1画面にまとめた、非公式のファンメイド計算ツールです。

- 📄 **HTMLファイル1枚だけ** — インストール不要、外部ライブラリもゼロ
- 📱 **PCでもスマホでも** そのまま使えます
- 🔒 データは **あなたの端末のブラウザ内だけ** に保存され、どこにも送信されません

## できること

### 🎯 育成シミュレート

画面は上から順に埋めていくだけです。

| # | やること | ポイント |
|---|---|---|
| 1 | **初期能力値設定** | 登録ポジションは最初 **「—」（未選択）**。育成したい選手の**登録ポジション（カードの左上）**を選ぶと Lv.1 の初期能力値が自動セット。「スライダー / 手入力で調整」で実数値に上書きし、モーダル右上の赤い**「入力を確定して閉じる」**を押します |
| 2 | **選手情報** | 名前・プレースタイル・体格・利き足・逆足・調子の波（大きい／普通／小さい）・**最大レベル（必須）**。最大レベルを入れるまで育成できません |
| 3 | **ポジション設定** | ピッチのマスをタップして適性を「薄い緑 → 濃い緑 → なし」で切り替え |
| 4 | **ブースター** | 全29種から最大2つ。ブースター1は **+4**（ビッグタイム等）まで対応。**同じブースターは2枠に入れられません**（効果の二重適用を防止） |
| 5 | **監督** | 適性数値（85〜90）による全体補正＋能力値を+1するバフを最大2つ。**監督プリセット**として保存でき、画面には使用中の1人だけを表示。「呼び出す」から保存済みを選択 |
| 6 | **スキル** | 初期搭載 最大10個／追加 最大5個。重複選択は自動でブロック。それぞれに赤い**リセット**ボタン付き |
| 7 | **能力値から育成** | **能力名をタップ**するとその場でスライダーが開く。右の「振った数」は**手入力もできる**数値欄（0〜16）で、下の目盛りにも点灯します（推定総合値の表示はこのパネルにはありません） |

**入力もれ防止** — **登録ポジション / 初期能力値 / 最大レベル** の3つが未入力だと、画面上部に赤い警告が出て、該当の入力欄が赤枠になります。

**初期能力値の入力** — スライダーには **40/50/60/70/80/90/99 の目盛り**が付き、**−＋ボタン**で1ずつ動かせます（**長押しで連続加減算**、押し続けると加速）。数値欄はスマホのキーボードが数字＋「次へ」になり、**改行を押すと次の能力へ**進みます。

**再現しているルール**

- タレントポイントは `(最大Lv − 1) × 2`。コストは同カテゴリを伸ばすほど増加（+1〜4は1pt / +5〜8は2pt / +9〜12は3pt / +13〜16は4pt）
- 能力値の上限は **99**。ただし **ブースターの上昇分だけ99を超えられます**（例：ゴールセービング+3のGKはGKセンス102まで）
- 監督の適性数値による補正（90なら 83以上が+3、56〜82が+2、40〜55が+1）
- 特殊スキル21種は後から追加できないカード固有スキルとして区別

**精度** — BTジュード・ベリンガム（OMF / 最大Lv.32 / TP62 / 最大総合値108）の実データと照合し、育成後の **26項目中23項目が完全一致・残りも±1**（平均誤差 0.115）、推定総合値も108で一致しています。

### 📊 保存・比較

操作はチェックボックスだけ。比較ボタンはありません。

- 一覧でチェックを**1つ**入れると、その選手の能力がそのまま下に開きます
- **2人目にチェックを入れた時点で自動的に比較表**へ切り替わり（最大4人）
- 各能力で最高＝緑／最低＝赤に色分け。**差異は2人を並べたときだけ**右端に表示します
- 「選手情報」ブロックに **プレースタイル / 利き足 / 逆足 頻度 / 逆足 精度 / コンディションの波 / 怪我耐性**
- 利き足は**足のマーク**で表示（左足＝左・右足＝右／利き足は塗りつぶし、逆足は薄い点線）
- カテゴリー（オフェンス等）は大きな見出しで区切り。選手の列は横幅いっぱいに等分されます
- 能力名は折り返さず1行、色は数値のまわりの小さなボックスにだけ付きます
- 表はパネル内で切らず**全体を表示**。ページごとスクロールでき、選手名の行は上に固定されます
- スキルも同じ表の形式で比較。**1行＝1スキル**で、持っている選手にチェックが付きます（初期搭載／追加の区別なく1つのリストに統合）
- **2人以上が持っているスキルは ⭐️＋人数つきの金色**で、リストの**いちばん上**にまとまります
- **「選択取り消し」** でチェックと比較パネルをまとめて解除
- **「育成消去」**（赤）で保存した育成をすべて削除。誤操作しないよう**確認は2回**出ます（確認はアプリ内のダイアログで表示されます）

### 📈 戦績管理

- フェーズごとに **期間・開始Division・開始レート** を設定。初回の開始日は **2026/08/13**、終了日は空です
- 終了日の欄の下に **開始の28日後に最も近い木曜日** がピンク色の候補で出ます。押すとそのまま入ります
- **終了日が空のあいだは試合を記録できません**（「記録する」が押せず、案内が出ます）
- 開始Divisionを選ぶと開始レートの目安が自動入力（**Div.1＝1800 / Div.2＝1500 / Div.3＝1200**）。手入力した値は上書きしません
- 期間が過ぎると**次フェーズが自動生成**され、Divisionと到達レートを引き継ぎ
- 成績サマリーは **「このフェーズ」／「全期間」** で切替（「このフェーズ」はフェーズ選択と連動）
- 試合の日付は **2026/08/13** が初期値。自分のチームスタイル・フォメは **「固定」** ボタン（水色→タップでピンク）で固定でき、記録のたびに選び直す必要がありません
- 相手側の入力は **相手のチームスタイル / 相手のフォメ / 相手のDivision**
- 勝率を **自分のスタイル別 / 自分のフォメ別 / 相手のスタイル別 / 相手のフォメ別** の4軸で集計
- 試合ログは **「表示中のフェーズ」／「全フェーズ（分けて表示）」** を切替。全フェーズではフェーズごとに見出し（試合数・勝率・レート）が入ります
- レート推移グラフ、CSV書き出し

### 🎴 スキル在庫

- スキル追加で出たスキルを在庫として登録・継承管理
- 在庫リストは **系統ごとに色分け**（ドリブル系＝青／パス系＝緑／シュート系＝オレンジ／ディフェンス系＝紫／GK系＝黄／その他＝グレー）
- **検索バー**で スキル名・系統名（「ドリブル系」など）・継承先・メモ を横断検索。「系統でしぼる」プルダウンと併用できます
- 状態の切替は **すべて / 在庫のみ / 継承済み**
- 「継承」を押すとアプリ内のダイアログが開き、**継承した選手名**と**継承日（任意）**を記録。選手名は保存済みの育成から候補が出ます
- **継承済みの行は取得日のかわりに継承日**を表示し、スキル名に**二重取り消し線**が入ります
- WISHバッジは**在庫として残っているスキルだけ**に付きます（継承済みには付きません）
- ウィッシュリストは画面の高さに合わせて広く表示（最大560px）。在庫と自動照合し、ダブり回数も集計
- ウィッシュリストの**「削除」**は、1つ以上選んでいると**赤く**なり件数を表示。押すと確認のうえリストを空にします（在庫データは消えません）
- 後から付けられない特殊スキルは対象から自動除外

### 🖼 画像で保存

育成カードを **PNG** で書き出せます。SNSにそのまま投稿できる縦長レイアウトで、能力値・ポジション適性・育成内容が1枚にまとまります。

- **PC（Mac / Windows）** … **「名前をつけて保存」ダイアログ**が開き、保存先とファイル名（初期値は選手名）を選べます。Chrome / Edge が対象で、Safari・Firefox は従来どおりダウンロードされます
- **スマホ** … 共有シートから直接送れます。Xなどに送るときは**画像だけ**で、ポスト本文は空です（文章を入れたいときは「シェア文をコピー」から）

## 使いはじめる

### そのまま使う

`index.html` をダウンロードしてダブルクリックするだけです。

### スマホのホーム画面に置く

1. ブラウザでページを開く
2. **iPhone (Safari)** → 共有ボタン → 「ホーム画面に追加」
3. **Android (Chrome)** → 右上の ⋮ → 「ホーム画面に追加」

アプリのように全画面で起動します。

### バックアップ

右上の **「データ」→「JSONで書き出し」**。
ブラウザのデータを消すと保存内容も消えるので、ときどき書き出しておくと安心です。別の端末で使いたいときは「JSONを読み込み」で取り込めます。

## GitHubで公開する

はじめて公開する場合の手順です。**ターミナルは不要**です。

### 1. リポジトリを作る

1. GitHubにログイン → 右上の **「+」→ New repository**
2. **Repository name** に `pitch-lab` と入力
3. **Public** を選択 ← ここ重要（無料プランではPublicでないとPagesが使えません）
4. **Create repository** をクリック

### 2. ファイルを置く

1. 作成直後の画面にある **「uploading an existing file」** をクリック
2. `index.html` と `README.md` をドラッグ＆ドロップ
3. 下までスクロールして **Commit changes**

### 3. 公開設定をする

1. リポジトリ上部の **Settings**
2. 左メニューの **Pages**
3. **Source** … `Deploy from a branch`
4. **Branch** … `main` ／ `/ (root)` を選んで **Save**
5. 1〜2分待つと、同じ画面の上部に公開URLが表示されます

```
https://<あなたのユーザー名>.github.io/pitch-lab/
```

このURLをスマホで開いて、ホーム画面に追加すれば完成です。

## 中身をアップデートする

新しい `index.html` に差し替える手順です。

### 方法A：画面から差し替える（かんたん・おすすめ）

1. リポジトリのトップで **Add file → Upload files**
2. 新しい `index.html` をドラッグ＆ドロップ
   （**同じファイル名なら自動で上書き**されます）
3. **Commit changes** をクリック
4. 1〜2分でURLに反映されます

> 💡 反映されないように見えるときは、ブラウザの**強制リロード**を試してください。
> PC: `Ctrl`（Macは `Cmd`）+ `Shift` + `R` ／ スマホ: いったんタブを閉じて開き直す

### 方法B：1ファイルだけ直接編集する

1. リポジトリで `index.html` をクリック
2. 右上の **鉛筆アイコン（Edit this file）**
3. 編集して **Commit changes**

### 方法C：ターミナルを使う

```bash
cd path/to/pitch-lab      # index.html があるフォルダ

git add .
git commit -m "PITCH LAB を更新"
git push
```

初回だけ、リポジトリとの接続が必要です。

```bash
git init
git branch -M main
git remote add origin https://github.com/<ユーザー名>/pitch-lab.git
git add .
git commit -m "PITCH LAB を公開"
git push -u origin main
```

## 困ったときは

| 症状 | 原因と対処 |
|---|---|
| URLが表示されない | Settings → Pages で **Source** と **Branch** を設定して **Save** したか確認。設定後1〜2分待つと上部にURLが出ます |
| Pages の項目が見つからない | リポジトリが **Private** になっています。無料プランでは **Public** にしてください（Settings → 一番下 → Change repository visibility） |
| 開いても 404 | ファイル名が `index.html` になっているか確認（**大文字・小文字も区別されます**）。`Index.html` や `pitch-lab.html` ではPagesのトップになりません |
| 更新が反映されない | 反映まで1〜2分かかります。それでもダメなら強制リロード |
| 保存データが消えた | データはブラウザ・端末ごとに独立しています。別の端末やシークレットウィンドウでは共有されません。JSON書き出しで移行してください |

## データの扱い

- 入力したデータは**サーバーに送信されません**。すべて端末内（localStorage）に保存されます
- GitHub Pages で公開しても、**あなたの育成データが他人に見えることはありません**。公開されるのはHTMLファイルそのものだけです
- 「共有リンクをコピー」で作られるURLには、その育成1件ぶんのデータだけが埋め込まれます

## 免責

本ツールは非公式のファンメイド計算機です。ゲーム本体および権利者とは一切関係ありません。
総合値は公開されていない計算式を独自に推定した**参考値**であり、実機と数ポイントずれることがあります。
