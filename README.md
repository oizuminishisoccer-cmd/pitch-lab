# PITCH LAB ⚽

育成シミュレート / 戦績管理 / スキル在庫 を1画面にまとめた、**非公式のファンメイド計算ツール**です。

- **HTML 1ファイルだけ**で動きます（CDN・外部ライブラリ一切なし）
- **PCでもスマホでも**そのまま使えます
- データは**あなたの端末のブラウザ内（localStorage）にだけ**保存されます。サーバーには何も送信しません

---

## 主な機能

### 育成シミュレート
- 登録ポジションを選ぶと素の能力値を自動セット（スライダー / 手入力で調整可）
- **能力名をタップ**するとそのカテゴリのスライダーが開き、その場で育成できる
- タレントポイントのコスト曲線（+1〜4は1pt / +5〜8は2pt / +9〜12は3pt / +13〜16は4pt）を再現
- 選手ブースター（29種・最大2つ）／監督ブースター（能力値+1のバフ・最大2つ）／監督の適性数値による全体補正
- ポジション適性をピッチ図でタップ設定
- 推定総合値・レーダーチャートをリアルタイム表示
- 育成カードを **PNG** で書き出し（スマホは共有シートからそのままXへ）

### 保存・比較
- 保存した育成を **最大4人**まで並べて比較
- 各能力で最高＝緑／最低＝赤に色分け、右端に**差異**を表示
- スキル（初期搭載／追加）も並べて比較

### 戦績管理
- フェーズの期間を決めると、期間終了後に**次フェーズを自動作成**
- 自分のスタイル別 / 自分のフォメ別 / 相手のスタイル別 / 相手のフォメ別 の4軸で勝率を集計
- レート推移グラフ、CSV書き出し

### スキル在庫
- スキル追加で出たスキルを在庫として登録・継承管理
- ウィッシュリストと自動照合、ダブり回数の集計
- 後から追加できない**特殊スキル**は対象から自動で除外

## 使い方

### そのまま使う
`index.html` をダウンロードしてダブルクリックするだけです。

### スマホのホーム画面に置く
1. ブラウザでページを開く
2. **iPhone (Safari)**：共有ボタン → 「ホーム画面に追加」
3. **Android (Chrome)**：右上の︙ → 「ホーム画面に追加」

アプリのように全画面で起動します。

### データのバックアップ
右上の「データ」→「JSONで書き出し」。
ブラウザのデータを消すと保存内容も消えるので、定期的に書き出しておくと安心です。
別の端末で使いたいときは、書き出したJSONを「JSONを読み込み」で取り込めます。

## GitHub Pages で公開する（無料・数分）

### A. 画面だけで完結する方法（ターミナル不要）

1. GitHub にログイン → 右上の **「+」→「New repository」**
2. **Repository name** に `pitch-lab` と入力
3. **Public** を選択（Pages を無料で使うため）
4. **「Create repository」** をクリック
5. 作成後の画面で **「uploading an existing file」** をクリック
6. `index.html`（と、この `README.md`）をドラッグ＆ドロップ
7. 下の **「Commit changes」** をクリック
8. リポジトリ上部の **「Settings」** → 左メニューの **「Pages」**
9. **Source** を `Deploy from a branch`、**Branch** を `main` / `/ (root)` にして **Save**
10. 1〜2分待つと、Pages の画面に公開URLが出ます

```
https://<あなたのユーザー名>.github.io/pitch-lab/
```

このURLをスマホで開けばOK。ホーム画面に追加すればアプリのように使えます。

### B. ターミナルを使う方法

```bash
# 1. index.html があるフォルダに移動
cd path/to/pitch-lab

# 2. Gitリポジトリとして初期化
git init
git branch -M main

# 3. ファイルを登録してコミット
git add .
git commit -m "PITCH LAB を公開"

# 4. GitHub上で作った空のリポジトリと接続（URLは自分のものに置き換え）
git remote add origin https://github.com/<ユーザー名>/pitch-lab.git

# 5. アップロード
git push -u origin main
```

そのあと **Settings → Pages** で上の 9〜10 と同じ設定をします。

### 更新するとき

- **画面から**：リポジトリ上で `index.html` を開く → 鉛筆アイコン → 編集 → Commit
  （丸ごと差し替えるなら「Add file → Upload files」で同名ファイルを上げ直すだけ）
- **ターミナルから**：

```bash
git add .
git commit -m "更新内容のメモ"
git push
```

反映まで1〜2分かかります。変わっていないように見えるときは、ブラウザの**強制リロード**（PC: `Ctrl`/`Cmd` + `Shift` + `R`）を試してください。

### つまずきやすいポイント

| 症状 | 原因と対処 |
|---|---|
| 404 になる | ファイル名が `index.html` になっているか確認（大文字小文字も区別されます） |
| Pages の項目がない | リポジトリが Private になっている。無料プランでは Public にする必要があります |
| 変更が反映されない | 反映に1〜2分かかります。それでもダメなら強制リロード |
| データが消えた | localStorage はブラウザ・端末ごとに独立しています。別の端末やシークレットウィンドウでは共有されません |

## データの扱いについて

- 入力したデータは**サーバーに送信されません**。すべて端末内に保存されます
- GitHub Pages で公開しても、**あなたの育成データが他人に見えることはありません**（見えるのはHTMLファイルだけです）
- 「共有リンクをコピー」で作られるURLには、その育成1件ぶんのデータだけが埋め込まれます
