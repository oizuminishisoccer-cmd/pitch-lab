# PITCH LAB ⚽

**育成シミュレート / 戦績管理 / スキル在庫** を1画面にまとめた、非公式のファンメイド計算ツールです。

- 📄 **HTMLファイル1枚だけ** — インストール不要、外部ライブラリもゼロ
- 📱 **PCでもスマホでも** そのまま使えます
- 🔒 データは **あなたの端末のブラウザ内だけ** に保存され、どこにも送信されません

## できること

### 🎯 育成シミュレート

画面は上から順に埋めていくだけです。

| # | やること | ポイント |
|---|---|---|
| 1 | **初期能力値設定** | 登録ポジションを選ぶと Lv.1 の初期能力値が自動セット。スライダー／手入力で上書きも可 |
| 2 | **選手情報** | 名前・プレースタイル・体格・利き足・逆足・最大レベル |
| 3 | **ポジション設定** | ピッチのマスをタップして適性を「薄い緑 → 濃い緑 → なし」で切り替え |
| 4 | **ブースター** | 全29種から最大2つ。ブースター1は **+4**（ビッグタイム等）まで対応 |
| 5 | **監督** | 適性数値（85〜90）による全体補正＋能力値を+1するバフを最大2つ。**監督プリセット**として保存でき、画面には使用中の1人だけを表示。「呼び出す」から保存済みを選択 |
| 6 | **スキル** | 初期搭載 最大10個／追加 最大5個。重複選択は自動でブロック |
| 7 | **能力値から育成** | **能力名をタップ**するとその場でスライダーが開く |

**再現しているルール**

- タレントポイントは `(最大Lv − 1) × 2`。コストは同カテゴリを伸ばすほど増加（+1〜4は1pt / +5〜8は2pt / +9〜12は3pt / +13〜16は4pt）
- 能力値の上限は **99**。ただし **ブースターの上昇分だけ99を超えられます**（例：ゴールセービング+3のGKはGKセンス102まで）
- 監督の適性数値による補正（90なら 83以上が+3、56〜82が+2、40〜55が+1）
- 特殊スキル21種は後から追加できないカード固有スキルとして区別

**精度** — BTジュード・ベリンガム（OMF / 最大Lv.32 / TP62 / 最大総合値108）の実データと照合し、育成後の **26項目中23項目が完全一致・残りも±1**（平均誤差 0.115）、推定総合値も108で一致しています。

### 📊 保存・比較

- 保存した育成を **最大4人** まで並べて比較
- 各能力で最高＝緑／最低＝赤に色分け、右端に**差異**を表示
- スキルも並べて比較

### 📈 戦績管理

- フェーズごとに **期間・開始Division・開始レート** を設定
- 期間が過ぎると**次フェーズが自動生成**され、Divisionと到達レートを引き継ぎ
- 勝率を **自分のスタイル別 / 自分のフォメ別 / 相手のスタイル別 / 相手のフォメ別** の4軸で集計
- レート推移グラフ、CSV書き出し

### 🎴 スキル在庫

- スキル追加で出たスキルを在庫として登録・継承管理
- ウィッシュリストと自動照合、ダブり回数も集計
- 後から付けられない特殊スキルは対象から自動除外

### 🖼 画像で保存

育成カードを **PNG** で書き出せます。SNSにそのまま投稿できる縦長レイアウトで、能力値・ポジション適性・育成内容が1枚にまとまります。スマホでは共有シートから直接送れます。

## 使いはじめる

### そのまま使う

`index.html` をダウンロードしてダブルクリックするだけです。

### スマホのホーム画面に置く

1. ブラウザでページを開く
2. **iPhone (Safari)** → 共有ボタン → 「ホーム画面に追加」
3. **Android (Chrome)** → 右上の ⋮ → 「ホーム画面に追加」

アプリのように全画面で起動します。

### バックアップ

右上の **「データ」→「JSONで書き出し」**。
ブラウザのデータを消すと保存内容も消えるので、ときどき書き出しておくと安心です。別の端末で使いたいときは「JSONを読み込み」で取り込めます。

## GitHubで公開する

はじめて公開する場合の手順です。**ターミナルは不要**です。

### 1. リポジトリを作る

1. GitHubにログイン → 右上の **「+」→ New repository**
2. **Repository name** に `pitch-lab` と入力
3. **Public** を選択 ← ここ重要（無料プランではPublicでないとPagesが使えません）
4. **Create repository** をクリック

### 2. ファイルを置く

1. 作成直後の画面にある **「uploading an existing file」** をクリック
2. `index.html` と `README.md` をドラッグ＆ドロップ
3. 下までスクロールして **Commit changes**

### 3. 公開設定をする

1. リポジトリ上部の **Settings**
2. 左メニューの **Pages**
3. **Source** … `Deploy from a branch`
4. **Branch** … `main` ／ `/ (root)` を選んで **Save**
5. 1〜2分待つと、同じ画面の上部に公開URLが表示されます

```
https://<あなたのユーザー名>.github.io/pitch-lab/
```

このURLをスマホで開いて、ホーム画面に追加すれば完成です。

## 中身をアップデートする

新しい `index.html` に差し替える手順です。

### 方法A：画面から差し替える（かんたん・おすすめ）

1. リポジトリのトップで **Add file → Upload files**
2. 新しい `index.html` をドラッグ＆ドロップ
   （**同じファイル名なら自動で上書き**されます）
3. **Commit changes** をクリック
4. 1〜2分でURLに反映されます

> 💡 反映されないように見えるときは、ブラウザの**強制リロード**を試してください。
> PC: `Ctrl`（Macは `Cmd`）+ `Shift` + `R` ／ スマホ: いったんタブを閉じて開き直す

### 方法B：1ファイルだけ直接編集する

1. リポジトリで `index.html` をクリック
2. 右上の **鉛筆アイコン（Edit this file）**
3. 編集して **Commit changes**

### 方法C：ターミナルを使う

```bash
cd path/to/pitch-lab      # index.html があるフォルダ

git add .
git commit -m "PITCH LAB を更新"
git push
```

初回だけ、リポジトリとの接続が必要です。

```bash
git init
git branch -M main
git remote add origin https://github.com/<ユーザー名>/pitch-lab.git
git add .
git commit -m "PITCH LAB を公開"
git push -u origin main
```

## 困ったときは

| 症状 | 原因と対処 |
|---|---|
| URLが表示されない | Settings → Pages で **Source** と **Branch** を設定して **Save** したか確認。設定後1〜2分待つと上部にURLが出ます |
| Pages の項目が見つからない | リポジトリが **Private** になっています。無料プランでは **Public** にしてください（Settings → 一番下 → Change repository visibility） |
| 開いても 404 | ファイル名が `index.html` になっているか確認（**大文字・小文字も区別されます**）。`Index.html` や `pitch-lab.html` ではPagesのトップになりません |
| 更新が反映されない | 反映まで1〜2分かかります。それでもダメなら強制リロード |
| 保存データが消えた | データはブラウザ・端末ごとに独立しています。別の端末やシークレットウィンドウでは共有されません。JSON書き出しで移行してください |

## データの扱い

- 入力したデータは**サーバーに送信されません**。すべて端末内（localStorage）に保存されます
- GitHub Pages で公開しても、**あなたの育成データが他人に見えることはありません**。公開されるのはHTMLファイルそのものだけです
- 「共有リンクをコピー」で作られるURLには、その育成1件ぶんのデータだけが埋め込まれます
